# CABIM · Diseño y construcción

Sitio completo en HTML, CSS y JavaScript. No necesita instalación, compilación ni servidor de aplicaciones.

## Publicar en GitHub Pages

1. Creá un repositorio en GitHub.
2. Subí el contenido de esta carpeta a la raíz del repositorio. `index.html` debe quedar en la raíz, junto con `servicios.html`, `contacto.html`, `style.css`, `app.js` y la carpeta `assets`.
3. En **Settings → Pages**, elegí **Deploy from a branch**.
4. Seleccioná la rama **main**, la carpeta **/ (root)** y guardá.
5. GitHub mostrará el enlace de la web cuando termine la publicación.

Los enlaces y las imágenes usan rutas relativas, compatibles con repositorios de GitHub Pages.

## Páginas

- `index.html`: inicio con hero, logo central, servicios y sección parallax.
- `servicios.html`: detalle de los servicios.
- `contacto.html`: datos de contacto, formulario para preparar una consulta por WhatsApp y mapa.
- `style.css`: estilos y adaptación a pantallas pequeñas.
- `app.js`: navegación compartida, footer, menú móvil y formulario.
- `assets/`: imágenes generadas y logos transparentes.
